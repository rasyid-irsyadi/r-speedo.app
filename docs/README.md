## Suggested learning order

1. Read the [product overview](product.md).
2. Check your hardware in [compatibility](compatibility.md).
3. Choose a workflow: [controller tuning](compatibility.md), [Motovlog](motovlog.md), [route/charging](route-and-navigation.md), [Road Dyno](road-dyno.md), [Dragger](dragger.md), or [Canvas](canvas.md).
4. Read [reports and data](reports-and-data.md) to understand what the numbers prove.
5. Read the [EV telemetry guide](ev-telemetry-guide.md) before interpreting SOC, range, current, power, or pack aggregates.

## The product in one sentence

R-Speedo is a phone-based EV cockpit for monitoring, protocol-specific controller tuning, multi-battery visibility, telemetry-backed Motovlog recording, route and charging support, and evidence-rich ride/performance reports.

## How to use this repository

- README answers “why use R-Speedo?” quickly.
- This index answers “where should I look next?”
- Each detail page keeps one subject, explicit limits, platform status, and a verification date.
- Compatibility names a status instead of implying that every model or firmware revision works.
- Road Dyno and Dragger are separate: Dyno compares setup changes; Dragger measures acceleration performance.
- Media lives in [`../media/`](../media/); the README shows the featured entry point and the complete archive.
