# R-Speedo privacy notes

Last verified: 2026-09-21

This public repository contains R-Speedo product documentation, learning pages, and supplied demo media. Account, payment, license, and trip experiences remain managed through the official application.

## Public media

Screenshots and video in this repository are copied from the media folder supplied by the R-Speedo maintainer for public documentation and marketing.

## Data on the device

R-Speedo keeps settings, profiles, trip/ODO state, BLE pairing preferences, TPMS state, report data, layout settings, charge session state, Dragger runs, Road Dyno runs/baselines, Canvas configurations, selected images, and Android widget snapshots on the device.

Ride/report data on the device is separate from anonymous analytics. A trip can remain available on the device while analytics sharing is disabled. Controller-setting snapshots, tuning context, multi-battery configuration, and Road Dyno baselines support personal comparison.

## Analytics

Anonymous EV analytics, when enabled according to the current in-app policy, provides aggregate product and market-fit insight. It uses an anonymous app identifier, privacy filtering, reduced telemetry, and small-sample protection rather than a public rider identity.

Live-rider sharing is separate from analytics. It is optional, location-based, and should be understood as a live visibility feature rather than an analytics feature.

## Deletion

R-Speedo provides in-app flows for deleting submitted analytics data and managing the account. The current app flow is the source for the active policy and user steps.
